# Portfolio Proyek Analisis Data (Python)

Repositori ini berisi kumpulan proyek portofolio pengolahan dan analisis data menggunakan bahasa pemrograman Python di Jupyter Notebook (`.ipynb`).

## Daftar Proyek:
1. **Retention Analysis**: Menganalisis tingkat retensi dan pola keaktifan pengguna terhadap produk atau layanan.
2. **User Segmentation**: Mengelompokkan pengguna berdasarkan karakteristik dan perilaku tertentu untuk kebutuhan strategi bisnis.
3. **Market Basket Analysis**: Mengidentifikasi pola asosiasi dan produk yang sering dibeli atau diakses secara bersamaan.

## Tech Stack:
* Python
* Pandas / Data Mining
* Jupyter Notebook
